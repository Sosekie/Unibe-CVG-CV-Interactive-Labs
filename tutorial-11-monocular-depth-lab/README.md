# Tutorial 11 - From Images to Depth

An interactive tutorial on monocular depth estimation, Depth Anything V2, Depth Pro and MoGe-2.
It combines precomputed predictions, paper figures, illustrative diagrams and worked questions.
The model demos linked from the tutorial run on external services.

## Run locally

Run `npm run dev` in this folder, or serve `dist/` with any static HTTP server.
Run `npm test` and `npm run build` to check and export the lab.

## Handouts

The [exercise sheet](materials/tutorial_11.pdf) and [worked solutions](materials/tutorial_11_solution.pdf) accompany the experiments.
The [LaTeX sources](materials/source/tex/) include the questions in both versions.
Compile `exercises.tex` and `solutions.tex` from that directory with `pdflatex`.
Image and prediction provenance is documented in [scripts/README.md](scripts/README.md).
