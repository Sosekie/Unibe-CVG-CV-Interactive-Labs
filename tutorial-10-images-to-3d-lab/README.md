# Tutorial 10 - From Images to 3D

An interactive tutorial on ambiguity in a single image, size priors and calibrated stereo, structure from motion, scene representations, and depth evaluation.
It includes optional affine factorisation and shortcut-learning experiments.
The examples are synthetic teaching models, not pretrained reconstruction systems or full bundle adjustment.

## Run locally

Run `npm run dev` in this folder and open the displayed local address.
Run `npm test` and `npm run build` to validate and export the static lab.
